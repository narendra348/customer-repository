# 🚀 Customer Complaint Management System

### SmartBridge Internship Project

A modern full-stack web application for managing customer complaints with separate dashboards for **Customers**, **Agents**, and **Administrators**.

# 📖 Project Overview

The **Customer Complaint Management System** is a full-stack MERN application developed during the **SmartBridge Internship**.

The system provides an efficient platform for customers to register complaints, administrators to assign complaints to agents, and agents to resolve issues while keeping customers informed throughout the complaint lifecycle.

---

# 🎯 Objectives

- Improve complaint management efficiency
- Reduce manual tracking
- Enable role-based access
- Provide real-time complaint monitoring
- Maintain complaint history
- Improve customer satisfaction

# 🛠 Technology Stack

| Frontend | Backend | Database | Authentication |
|-----------|----------|-----------|----------------|
| React.js | Node.js | MongoDB Atlas | JWT |
| Bootstrap | Express.js | Mongoose | bcrypt |
| Axios | REST API | MongoDB | Protected Routes |

---

# 🏗 System Architecture

```text
                  Customer
                      │
                      ▼
             React Frontend (Vercel)
                      │
                REST API (Axios)
                      │
                      ▼
            Node.js + Express Backend
                      │
                JWT Authentication
                      │
                      ▼
                MongoDB Atlas Database
```
